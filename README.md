# 🍐 Liquid Glass – Theme for Pear Desktop

https://github.com/user-attachments/assets/9f685d8e-dfa9-4295-8e0c-4b281d2e7567

(The preview uses a transparent acrylic type effect with 10% opacity)

A clean, **Apple iOS-style Liquid Glass theme** built for the
👉 **Pear Desktop music player:**
https://github.com/pear-devs/pear-desktop

The theme gives Pear a dark, grey, frosted-glass look: a floating glass player bar, clear glass panels and a calm graphite palette. You can also turn the album art into a **spinning vinyl record on a turntable**, all in pure CSS with no plugins.

---

## 🎨 Three Versions
Pick the one you like. Each is a single CSS file.

| File | What you get |
| --- | --- |
| `liquid-glass.css` | The plain Liquid Glass theme. Rounded album art, no turntable. |
| `liquid-glass-player-without-lid.css` | Liquid Glass + a vinyl turntable in place of the album art. |
| `liquid-glass-player-with-lid.css` | Same turntable, plus a clear dust cover that opens when you hover. |

---

## ✨ Features
- 🧊 Grey, frosted Liquid Glass styling across the app
- 🎚️ Floating glass player bar with even edges
- ⚪ White seek bar that curves with the player bar's corners
- 🔍 Single glass pill search box with a clean suggestions panel
- 💊 Glass chips (Relax, Energize, Workout…) with one bubble each
- 📋 Queue panel centered between the top bar and the player bar
- 🖼️ Rounded mini player (the small picture above the player bar)
- 🌫️ Works with Pear's built-in **Transparent Player** plugin (Mica / Acrylic)

### 💿 Turntable versions
- The song's cover becomes the whole record (a picture disc), with grooves and a light sheen
- The record **spins while music plays** and stops when you pause
- The tonearm **swings onto the record** when a song starts and glides back to its rest on pause
- Plinth with platter rim, tonearm base, buttons and a speed switch, viewed at a slight 3D angle
- **With-lid version:** a clear acrylic dust cover on back hinges that opens on hover
- Full screen and video mode show the normal image or video

## 📦 Installation
1. Install **Pear Desktop**: https://github.com/pear-devs/pear-desktop
2. Download one of the CSS files from this repo.
3. In Pear, open **Options → Visual Tweaks → Themes → Import custom CSS file** and choose the file.
4. Restart Pear (or **Reload App**) to apply it.

> 💡 Only load **one** of the three files at a time. If you update a file, remove the old one from the theme list first, so Pear doesn't keep the old copy.

## ⚠️ Notes
- Playback detection checks the player's **Pause** button label, which is English, and the queue's playing state, which works in any language. If the record doesn't spin, open an issue and say which UI language you use.
- CSS can't make the tonearm follow the song's progress, and you can't drag to rotate the turntable.
- YouTube Music changes its page markup now and then, so some styles may need updates over time.
